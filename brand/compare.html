04What I'd flag before adopting either
Two serifs, not one. This wordmark is a sharp didone-ish face; the site's display is Instrument Serif, which is softer and more calligraphic. Side by side in the hero they don't rhyme. If this logo wins, the headline should move to a didone (Bodoni Moda is free and close) so the page and the logo are cut from the same cloth.
These are traces, not drawings. I recovered them from the supplied bitmaps, so the serifs carry a pixel of the image model's wobble. Perfectly fine on screen at every size above; for print, signage or anything larger than a screen, the wordmark wants redrawing from the same skeleton — a half-day job with the vector file attached.
“EST — 2026” needs confirming. The seal claims the studio was established this year. If Morgan has been trading longer, that badge is wrong and shouldn't go on anything printed.
